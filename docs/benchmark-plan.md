# Ollama 벤치마크 계획

## 목적

SER8의 16GB 메모리 환경에서 사용할 수 있는 모델의 범위를 확인하고, 기존 게임 서버와 함께 운영할 수 있는 기준을 정한다.

## 테스트 전 기록

- 시스템 유휴 메모리와 스왑 사용량
- CPU 사용률과 온도
- 디스크 여유 공간
- 실행 중인 Docker 컨테이너와 게임 서버

## 모델별 측정 항목

| 항목 | 기록 내용 |
| --- | --- |
| 모델 | 정확한 Ollama 태그와 양자화 정보 |
| 파일 크기 | 다운로드 후 실제 디스크 사용량 |
| 로딩 | 첫 응답까지 걸린 시간 |
| 생성 속도 | 초당 토큰 수 |
| 메모리 | 실행 전후 RAM 및 스왑 사용량 |
| CPU | 평균 및 최대 사용률 |
| 안정성 | 중단, 오류, 과도한 스왑 발생 여부 |
| 답변 품질 | 한국어, 요약, 코드 질문에 대한 체감 결과 |

## 테스트 시나리오

1. LLM만 실행한 상태
2. 가벼운 게임 서버와 동시 실행
3. 메모리 사용량이 큰 게임 서버와 동시 실행
4. 연속 요청 시 온도와 응답 속도 변화 확인

## 공정한 비교 기준

- 모델마다 같은 프롬프트를 사용한다.
- 첫 실행과 워밍업 이후 실행을 구분한다.
- 측정 중 다른 작업은 가능한 한 중단한다.
- 단독 실행 결과와 동시 실행 결과를 별도로 기록한다.
- 한 번의 결과로 확정하지 않고 반복 측정한다.

## 통과 기준

- 게임 서버에 눈에 띄는 지연이나 장애를 만들지 않는다.
- 지속적으로 스왑에 의존하지 않는다.
- 실제 대화와 간단한 코딩 보조에 사용할 수 있는 응답 속도를 낸다.
- 서버 재부팅 후 동일하게 재현할 수 있다.

후보 모델과 수치 기준은 첫 기초 측정 후 추가한다.
