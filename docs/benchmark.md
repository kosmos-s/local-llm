# 벤치마크

## 목적

SER8의 16GB 메모리 환경에서 로컬 모델의 응답 성능과 자원 사용량을 확인하고, 기존 게임 서버와 함께 운영할 수 있는 기준을 찾습니다.

## 테스트 환경

| 항목 | 환경 |
| --- | --- |
| 하드웨어 | Minisforum SER8 |
| CPU | AMD Ryzen 7 8745HS |
| 메모리 | DDR5 16GB |
| 운영체제 | Ubuntu Desktop 24.04.4 LTS |
| 실행 환경 | Ollama |

## 테스트 모델

- `qwen3:8b` — 현재 메인 모델, 기본 추론 성공
- `qwen3:4b` — 초기 구동 시험에 사용, 정량 측정 기록 없음

## 측정 항목

- 첫 응답까지 걸린 시간
- 생성 속도
- RAM 및 스왑 사용량
- CPU 사용률과 온도
- 반복 요청 안정성
- 게임 서버 동시 실행 시 영향

## 결과

| 모델 | 기본 추론 | 첫 응답 시간 | 생성 속도 | 메모리 | 게임 서버 동시 실행 |
| --- | --- | --- | --- | --- | --- |
| `qwen3:8b` | 성공 | 측정 예정 | 측정 예정 | 측정 예정 | 미측정 |
| `qwen3:4b` | 초기 실행만 확인 | 측정 예정 | 측정 예정 | 측정 예정 | 미측정 |

## 기록 원칙

- 메인 운영 후보는 `qwen3:8b`입니다.
- 모델마다 같은 프롬프트를 사용합니다.
- 첫 실행과 워밍업 이후 실행을 구분합니다.
- 단독 실행과 게임 서버 동시 실행 결과를 따로 기록합니다.
- 측정하지 않은 값은 추측하지 않고 `측정 예정` 또는 `미측정`으로 남깁니다.
