# 현재 상황

마지막 업데이트: 2026-09-03

## 프로젝트 목적

현재 운영 중인 Ubuntu 홈 게임 서버를 유지하면서 같은 장비에서 로컬 LLM을 구동할 수 있는지 확인한다. 단순 설치가 아니라 성능, 메모리 사용량, 게임 서버와의 공존 가능성을 직접 측정하고 기록하는 것이 목표다.

## 현재 단계

> **Phase 1 — Ollama 구동 및 OpenClaw 기본 연동 완료, 벤치마크 진행 중**

초기 계획 수립 단계에서 실제 구현 단계로 넘어왔다. 모델 실행과 OpenClaw 설정은 확인했으며, 다음 작업은 수치 기반 성능·안정성 검증이다.

## 완료된 작업

- 프로젝트 목표, 범위, 단계별 구현 순서 결정
- GitHub 저장소와 문서 구조 구성
- Ollama 설치 및 `localhost:11434` 로컬 API 동작 확인
- `qwen3:4b` 다운로드 및 기본 추론 확인
- `qwen3:8b` 다운로드 및 한국어 응답 확인
- OpenClaw `2026.8.2` 설치
- OpenClaw 기본 모델을 `ollama/qwen3:8b`로 지정
- `openclaw models status`에서 기본 모델 설정 확인

## 현재 확인된 동작

### Ollama

- 모델이 없던 초기 상태에서 API 동작을 확인한 뒤 모델을 내려받았다.
- `qwen3:4b`는 CPU 추론으로 정상 응답했으며 실행 중 컨텍스트는 4096으로 확인했다.
- `qwen3:8b`는 직접 실행에서 한국어 프롬프트에 정상 응답했다.
- Qwen3의 사고 과정 출력 특성도 함께 확인했다.

### OpenClaw

- 설치 버전: `2026.8.2`
- 설정 파일: `~/.openclaw/openclaw.json`
- 기본 모델: `ollama/qwen3:8b`
- 별도 fallback·utility·image 모델은 아직 지정하지 않았다.

## 아직 하지 않은 작업

- 연속 요청 시 온도와 응답 속도 변화 측정
- Minecraft, Palworld, Project Zomboid 서버와 동시 실행 테스트
- 장시간 운영 및 재부팅 후 재현성 확인
- Open WebUI 설치
- RAG 구성
- OpenClaw 도구 권한과 자동화 범위 설계
- Pterodactyl 및 Discord 연동

## 현재 제약

### 메모리

시스템 메모리가 16GB이며 Radeon 780M 내장 그래픽도 시스템 메모리를 공유한다. 운영체제, Docker, Pterodactyl Wings, 게임 서버, LLM이 같은 자원을 사용하므로 모델 크기보다 전체 서비스 안정성이 우선이다.

### 기존 서비스와의 공존

이 장비는 Minecraft, Palworld, Project Zomboid 서버를 운영하는 24시간 서버다. LLM 단독 성능뿐 아니라 게임 서버와 동시에 실행할 때의 지연과 메모리 압박을 확인해야 한다.

### 저장공간

512GB SSD를 게임 서버 데이터, 컨테이너 이미지, 모델 파일이 함께 사용한다. 테스트가 끝난 모델은 필요성에 따라 정리한다.
