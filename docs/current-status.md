# 현재 상황

마지막 업데이트: 2026-09-02

## 프로젝트 목적

현재 운영 중인 Ubuntu 홈 게임 서버를 유지하면서 같은 장비에서 로컬 LLM을 구동할 수 있는지 확인한다. 단순 설치가 아니라 성능, 메모리 사용량, 게임 서버와의 공존 가능성을 직접 측정하고 기록하는 것이 목표다.

## 완료된 작업

- 프로젝트 목표와 범위 결정
- 서버 하드웨어 및 기존 서비스 정리
- 단계별 구현 순서 결정
- GitHub 저장소 생성
- 초기 문서 구조 작성

## 아직 하지 않은 작업

- Ollama 설치
- 모델 다운로드 및 성능 측정
- 메모리·CPU 사용량 기록
- 게임 서버 동시 실행 테스트
- Open WebUI 설치
- RAG 구성
- OpenClaw 연동
- Pterodactyl 및 Discord 연동

## 현재 제약

### 메모리

시스템 메모리가 16GB이며 Radeon 780M 내장 그래픽도 시스템 메모리를 공유한다. 따라서 운영체제, Docker, Pterodactyl Wings, 게임 서버, LLM이 같은 자원을 사용한다.

### 기존 서비스와의 공존

이 장비는 이미 Minecraft, Palworld, Project Zomboid 서버를 운영하는 24시간 서버다. LLM 성능보다 게임 서버 안정성을 먼저 보호해야 한다.

### 저장공간

512GB SSD를 게임 서버 데이터, 컨테이너 이미지, 모델 파일이 함께 사용한다. 모델을 무작정 여러 개 보관하지 않고 실제 사용 후보만 유지해야 한다.
